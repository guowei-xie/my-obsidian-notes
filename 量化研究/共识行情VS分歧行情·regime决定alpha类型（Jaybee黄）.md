# 共识行情 VS 分歧行情 · regime 决定 alpha 类型

## 一句话是什么

**不同的市场 regime 奖励不同类型的 alpha。** 分歧行情奖励**交易型 alpha**（广度、分散、赚散户情绪偏差的钱），共识行情奖励**认知型 alpha**（深研产业、重仓稀缺主线标的）。今年量化交易型 alpha 变薄，不是策略坏了，而是市场进入了**共识行情**。

## 为什么值得学（可迁移价值）

它给了一个**"环境决定方法有效性"的分析框架**：与其纠结"我的策略是不是失效了"，不如先判断"现在的环境奖励的是哪一类能力"。这套 regime 思维可迁移到任何"同一套方法在不同阶段效果迥异"的场景（如增长打法在扩张期 vs 存量期、内容策略在流量红利期 vs 存量竞争期）。作者反复强调：**这是一个理解框架，不是预测工具。**

## 背景现象（为什么诡异）

- 今年上半年市场收益主要集中在**双创（科创板+创业板）**。
- 用传统量化策略（分散化持仓、日频调仓、靠广度和纪律赚钱）的，今年**超额很薄**。
- 更诡异的是：`ret5`/`ret10` 这类**以前被市场唾弃的短期动量因子，今年 IC 居然也不低**。
- 作者读研报后的解释：**市场进入了共识行情。**

## 核心框架：两种 regime × 两种 alpha

### 共识行情 vs 分歧行情

| | 共识行情 | 分歧行情 |
|---|---|---|
| 特征 | 主流资金**抱团同一叙事**，形成资金正循环 | **无明确主线**，资金在不同板块/行业间轮动 |
| 历史例子 | 2017 漂亮50、2020–2021 新能源+半导体、（今年）AI/双创 | 2022–2025 |
| 成因 | 出现强大产业逻辑/趋势 → 机构押注同一方向 → 抱团核心龙头 → 越涨越买（主动+被动+散户）| 多条主线并存，未形成抱团 |
| 奖励哪种策略 | **深度**：重仓几只主线票 | **广度+分散**：分散化持仓靠纪律赚钱 |
| 奖励哪种 alpha | **认知型 alpha** | **交易型 alpha** |

### 交易型 alpha vs 认知型 alpha

| | 交易型 alpha | 认知型 alpha |
|---|---|---|
| 钱从哪来 | 捕捉市场当下的**定价偏差** | 对产业趋势的**基本面预判** |
| 典型手段 | 动量/反转赚散户追涨杀跌的情绪钱；tick 级/微观结构信息捕捉快速价格偏差 | 深研某产业链、对核心标的有独到认知，重仓具不可替代性/稀缺性的标的 |
| 信息来源 | 价量数据（散户也在的市场） | 价值投资/基本面分析/深度调研（散户一般拿不到） |
| 何时奏效 | **分歧行情**（散户非理性行为更多、更易被系统性捕捉） | **共识行情**（资金抱团主线） |

## 如何度量 regime：行业轮动速度

一个可操作的**后验**指标：

1. **取行业**：申万一级 31 个行业。
2. **算收益率**：每个行业内成分股**市值加权**，得到该行业收益率。
3. **截面排名**：对 31 个行业收益率做截面排名。
4. **月度变化**：本月排名截面 − 上月排名截面，取**绝对值**（每个行业排名的绝对变化）。
5. **求和**：把 31 个行业的绝对变化**加总** → 得到"行业轮动速度"。
6. **平滑（可选）**：噪音大就用过去 12/24/36 个月做平滑。

**解读**：轮动速度快 → 资金在行业间快速流动 → 偏**分歧行情**；轮动慢 → 资金抱团 → 偏**共识行情**。

> ⚠️ **只能后验，不能先验**：轮动是"发生之后往回看才看得见"的。能先验预测就能直接赚钱了——现实是只能后验判断当前处于哪种 regime。

## 市场集中度是波动的

- 共识行情的**反转逻辑**：主流标的越涨越买形成正循环，但涨到一定程度**性价比降低**，同时非主线标的变得**很便宜、性价比高**（估值洼地显现）→ 共识开始瓦解 → 转向分歧 → 市场重新奖励广度和分散。
- 所以**市场集中度不断波动**，共识行情与分歧行情**交替出现**。

## 当前判断（2026-07 视角，作者观点）

- 过去三周：科创暴跌，很多**之前失效的量化因子又开始有效** → 市场有**从共识向分歧过渡**的迹象。
- 但作者个人认为**共识行情还没走完**，主线资金可能还会**回流核心标的**。
- 所以"这段时间做量化确实比较惨"。
- （以上为口述观点，非结论；本篇价值在框架而非择时判断。）

## 术语速查

| 术语 | 含义 |
|---|---|
| 共识行情 | 主流资金抱团同一叙事、集中度高的市场阶段 |
| 分歧行情 | 无主线、资金在板块间轮动、集中度低的阶段 |
| regime | 市场状态/机制；不同 regime 奖励不同 alpha |
| 交易型 alpha | 靠捕捉定价偏差/情绪的钱（动量反转、微观结构、tick级）|
| 认知型 alpha | 靠深研产业、基本面预判、重仓稀缺主线标的的钱 |
| 行业轮动速度 | 申万一级31行业市值加权收益率的月度排名变化绝对值求和，判 regime |
| 双创 | 科创板 + 创业板 |
| ret5 / ret10 | 5日 / 10日收益率类短期动量因子 |
| IC | 信息系数，衡量因子预测方向的准确性 |
| 市场集中度 | 资金/收益向少数标的集中的程度，随共识/分歧交替波动 |
