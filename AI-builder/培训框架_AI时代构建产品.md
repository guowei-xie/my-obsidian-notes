## 三、模块详解

### 模块 0 · 开场与范式转变（30 min）
- 为什么是现在：AI 把「构建产品」的门槛从「会写代码」降到了「会描述需求」。
- 角色变化：PM/业务/分析师可以亲手做出可用原型，而不只是写文档提需求。
- 设定今天的边界：我们不培养工程师，而是让你**看懂全流程、能做技术决策、能自己跑通一个上线**。

### 模块 1 · AI 构建产品的基本盘（60 min）
- 核心名词扫盲（够用就好）：大模型 / 提示词 / API / Token。
- AI 构建工具地图：对话式编程（如 Claude、Cursor 等）、低代码/无代码、AI 生成前端。
- 现场演示：用自然语言让 AI 生成一个能跑的小应用。
- 关键认知：AI 帮你写代码，但**你要懂得提需求、看结果、做判断**。

### 模块 2 · 从想法到本地 Demo（60 min，动手）
- 动手练习：每人用 AI 工具做出一个本地能运行的小工具（如一个数据查询/小看板）。
- 引入「会一点 Python」的优势：能看懂、能微调 AI 生成的代码。
- 产出：一个在自己电脑上跑起来的 Demo——为下午「上线」做铺垫。

### 模块 3 · 本地 vs 上线——差距在哪（60 min）★主线
- 「在我电脑上能跑」≠「别人能用」：到底差了什么？
- 上线要补齐的几件事：让别人能访问（部署/托管）、稳定运行、密钥与配置、数据存储、域名与访问地址。
- 用一张图讲清「本地 Demo → 线上产品」的链路。

### 模块 4 · Web 应用结构与框架选择（60 min）
- 三层结构科普：前端（用户看到的）/ 后端（处理逻辑的）/ 数据库（存数据的）。
- 面向「会 Python」的人的最省心选择：
  - 纯 Python 快速出活：Streamlit、Gradio（几乎不用碰前端）。
  - 需要更灵活的后端：Flask、FastAPI。
  - 需要正经前端时再了解：React/Next.js 或交给 AI/无代码生成。
- 决策原则：**先问「要给谁用、用多久、要不要好看」，再选框架**，避免过度设计。

### 模块 5 · 发布上线全流程（60 min，动手）★主线
- 托管平台科普与对比：Streamlit Cloud、Hugging Face Spaces、Vercel、Render/Railway 等（按「上手难度 / 适合场景 / 免费额度」对比）。
- 动手：把上午的 Demo 部署成一个**有公开链接、同事点开就能用**的应用。
- 配套概念：环境变量与 API Key 怎么放、代码托管（Git/GitHub）是什么、为什么需要。

#### 5.1 域名 · DNS · 反向代理（约 25 min，科普向）

**为什么要讲这块**：托管平台给的默认链接（如 `xxx.streamlit.app`）能用，但又长又不正式。要变成 `tool.公司.com` 这种「自己的地址」，就绕不开域名、DNS、反向代理这三件事。用一个比喻串起来：**域名是店名，DNS 是电话黄页，反向代理是前台/门卫。**

- **域名（Domain）**：人类好记的网址（如 `company.com`）。
  - 从哪来：在域名注册商购买（阿里云、腾讯云、Cloudflare、GoDaddy 等），按年付费。
  - 概念：顶级域名（`.com`/`.cn`）、主域名（`company.com`）、子域名（`tool.company.com`，可免费随意加）。
  - 给非工程同学的关键点：一个主域名下可以挂很多子域名，不同工具各占一个，不用重复买。

- **DNS（域名解析）**：把「域名」翻译成服务器真实地址（IP）的「电话黄页」。
  - 你访问 `tool.company.com` 时，浏览器先问 DNS：「它在哪台机器上？」拿到 IP 再去访问。
  - 常见记录类型（够用就好）：`A 记录`（域名→IP）、`CNAME 记录`（域名→另一个域名，托管平台最常用）、`TXT 记录`（做验证用）。
  - 实操场景：在托管平台拿到一个目标地址，去域名后台加一条 CNAME 指过去，等几分钟到几小时「生效（DNS 传播）」即可。

- **反向代理（Reverse Proxy）**：站在你应用前面的「前台/门卫」，对外只暴露一个入口，再把请求分发给后面的应用。
  - 干什么用：统一入口、配 HTTPS 证书（小绿锁）、把多个服务挂在同一个域名下、做限流和挡攻击。
  - 常见角色：Nginx（经典自建）、Cloudflare（最省心，注册即用，还自带 CDN/防护）、各托管平台其实已内置反向代理。
  - 给非工程同学的关键点：用 Streamlit Cloud / Vercel 这类平台时，反向代理和 HTTPS **平台已经帮你做好了**，你主要操心的是「域名 + DNS 解析」；只有自建服务器时才需要自己配 Nginx。

- **HTTPS / SSL 证书**：地址栏的「小锁」，给传输加密。如今多数平台和 Cloudflare 都能**自动免费签发**，了解「为什么需要、由谁负责」即可。

- **一条龙串讲（演示）**：买域名 → 加一条 DNS 解析指向托管平台 → 平台自动配好反向代理与 HTTPS → 同事用 `tool.company.com` 直接访问。

### 模块 6 · 上线之后要操心的事（30 min）
- 成本：API 调用费、托管费，怎么估算、怎么不被「跑爆」。
- 安全与合规：密钥保护、用户数据与隐私、内部数据能不能传给外部模型。
- 持续运营：怎么知道有没有人用、出错了怎么发现、谁来维护。
- 何时该交给专业工程团队：原型自己做，规模化交给研发。

### 模块 7 · 总结 · 案例拆解 · 答疑（30 min）
- 回顾「想法 → 本地 Demo → 上线 → 运营」全链路。
- 拆解 1 个真实/贴近业务的案例。
- 自由答疑，收集后续深化培训的需求。
