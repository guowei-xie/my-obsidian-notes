## 一句话是什么

**普通人做 AI 量化最正确的第一步，不是问 AI"明天买什么"，而是问 AI"怎么把我的市场观察，转化成一个定义明确、时间正确、能被证伪的研究实验"。** AI 只是"更快验证 Alpha"的工具，它不会直接把 Alpha 送给你——而它最大的优势（快）同时也是它最大的风险（快到能高速批量制造过拟合）。

## 为什么值得学（可迁移价值）

这不是量化专属，而是一套"如何把大语言模型接进严肃研究流程"的通用范式。凡是想用 AI 做**先看数据、再下判断**的工作（策略回测、AB 实验、因子/特征研究、归因分析），都容易犯同一个错：让 AI 直接给结论。本篇给出的解法——**AI 负责理解与结构化信息，固定系统负责验证信息；给 AI 划定权限、只当没有签字权的研究员**——可直接迁移到任何"人机协作做研究"的场景。

## 核心主张总览

| # | 主张 | 要防的错 | 一句话 |
|---|---|---|---|
| 1 | 信号必须满足四条件 | 把"观点"当"信号" | 定义明确 / 时间明确 / 可计算 / 可回测，缺一不算量化 |
| 2 | 分清两类 AI 量化 | 把 LLM 当预测模型用 | 传统 ML 是预测模型；LLM 是研究助理，别混用 |
| 3 | AI 扮演五个角色 | 让 AI 一上来当资金经理 | 研究助理/数据检查/代码工程/实验管理/回测审计，均无签字权 |
| 4 | 搭最小 AI 量化系统 | 以为要自己训大模型买显卡 | 可靠数据 + 固定回测底座 + AI 沙盒 + 实验协议，四件即可起步 |
| 5 | 先做"研究假设卡" | 直接让 AI 写高收益策略 | 把模糊想法变成可证伪假设，先定"什么证据出现算它无效" |
| 6 | 纠正错误提示词 | 用带偏见的指令诱导 AI | 不求高收益、不求"证明有效"、每次只改一个变量 |

## 逐条拆解

### 1 · 什么才算"量化信号"：四个条件

普通人常见错法：把 K 线图/新闻/财报一股脑发给 AI，问"明天涨不涨""帮我选最有潜力的股票""直接给买入卖出持有"。**这不是 AI 量化，只是请了个语言模型来算命。**

判据很简单——只要 AI 给你的是"我认为它会上涨"，但中间**没有明确的数据、公式、时间点和验证规则**，那就只是一个观点，不是信号。真正的量化信号至少满足四条：

1. **定义明确**：如"最近涨得好"要说清是 5 天、20 天还是 60 天；是绝对涨幅还是相对大盘/行业的涨幅。
2. **时间明确**：信号在什么时点计算完成？用了今天收盘价，最早什么时候才能买入？
3. **可以计算**：字段、公式落到可执行。
4. **可以回测**：持有 1 天 / 5 天 / 20 天？**加入手续费、滑点和真实成交限制后**还有没有收益？

> 这些问题不解决就让 AI 直接选股，它输出的只是"听起来很专业的文字"。

### 2 · 分清两种完全不同的"AI 量化"

大家口中的"AI 量化"其实混了两样东西：

| | 传统机器学习模型 | 大语言模型 / AI Agent |
|---|---|---|
| 代表 | XGBoost、LightGBM、随机森林、神经网络 | GPT 类 LLM 与 Agent |
| 输入 | 结构化数据（动量、波动率、成交量、估值、资金流…） | 研报、新闻、代码、公式、数据需求 |
| 输出 | 未来收益预测 / 上涨概率 / 股票排名 | 阅读提取、整理、写代码、跑回测、解释结果、写报告 |
| 本质 | **本身就是预测模型**（需特征、标签、训练/验证/测试集） | **像研究助理**，不是现成的股价预测器 |

**普通人最容易犯的错，就是把第二种（LLM）当第一种（预测模型）用**——直接问"明天哪只涨"。它会按看过的文字和模式编一个答案，但不一定经过严格统计检验，也不一定考虑真实交易条件。

**正确结构**：不是"新闻/K线 → AI → 直接买卖"，而是"市场信息 → AI 先变成结构化数据 → 固定量化系统回测验证"。

以研究新闻情绪为例：
- ❌ 错法：让 AI 读完新闻直接说"买入"。
- ✅ 对法：让 AI 只负责**提取并结构化**——事件类型（订单/业绩/政策/诉讼/管理层变动）、情绪方向（正/负/中）、是否超预期、信息来源（公告/媒体/传闻）、AI 自评置信度。例：`事件类型=业绩预告, 情绪=正面, 超预期程度=0.8, 来源=公司公告, 发布时间=18:32, 置信度=0.92`。
- 再由量化系统测试：这些字段和未来 1/5/20 天收益到底有没有**稳定关系**。

> 一句话：**AI 负责理解信息，量化系统负责验证信息。**

### 3 · 让 AI 承担的五个角色（都没有签字权）

| 角色 | 职责 | 关键约束 |
|---|---|---|
| ① 研究助理 | 面对一个模糊观察，帮你想清：需要哪些数据？信号怎么定义？可能的逻辑机制？和什么基准比？在什么情况下会失效？ | 只提问题与假设，不下结论 |
| ② 数据检查员 | 每个字段什么意思？数据何时产生、投资者何时**真正能看到**？有无缺失值 / 复权问题 / 幸存者偏差 / 用今天的股票池回测十年前 | 专挑数据时点与偏差的坑 |
| ③ 代码工程师 | 按你规定的接口写因子、数据处理、回测配置、单元测试 | **必须限定范围**，不能为提高收益去改回测框架 |
| ④ 实验管理员 | 记录：这次改了什么？为什么改？改前预期？样本内结果？样本外结果？最终成功还是失败 | 全过程留痕 |
| ⑤ 回测审计员 | 专找未来函数、数据泄露、不真实成交、过拟合、参数敏感、交易成本与容量问题 | 唱反调、找漏洞 |

> **最重要的原则**：不要让 AI 一上来就当资金经理。先让它当一个**没有签字权的量化研究员**——它能提建议、写代码、批评策略，但不能因为一句"我认为这只会涨"就直接控制你的资金。

### 4 · 普通人最小 AI 量化系统：四个部件

不需要自己训大模型、买显卡、先啃深度学习。起步只要四样：

**① 可靠的数据**
日线/分钟线/财务/新闻，或你自己的交易记录。数据不必多，但**每个字段都要说清**：代表什么、单位、何时产生、何时可用、有无后期修订、有无缺失、有无复权。建议单独建一个**数据字典**。
> 很多回测错误不是策略逻辑错，而是研究者根本没搞清**数据什么时候才能用**。

**② 固定的回测底座（全系统最关键处）**
至少固定：股票池、复权方式、停牌处理、涨跌停处理、手续费、印花税、滑点、买卖价格、调仓时间、持有周期、绩效指标。
> 为什么必须固定？假设原策略是"次日开盘买入"，AI 为了让结果更好偷偷改成"今日收盘买入"；或原本算了滑点，AI 重写代码时把滑点删了——收益确实上去了，但你根本分不清是**因子变好**还是**回测规则被改松**。
>
> 所以要给 AI 设权限：**AI 只改研究模块，不改成交规则。**

**③ AI 研究沙盒**
建一个专门给 AI 工作的目录，只允许它改有限文件，底层回测引擎设为**只读**：

| 文件 | 作用 |
|---|---|
| `hypothesis.md` | 研究假设 |
| `data_dictionary.md` | 字段定义与数据时间 |
| `factor.py` | 因子计算 |
| `test_factor.py` | 单元测试 |
| `config.yaml` | 回测参数 |
| `experiment_log.csv` | 所有成功与失败的实验 |
| 审计报告 | 风险审计结果 |

> 这样 AI 不会因为某次结果不好，就把你底层的成交规则一起改掉。

**④ 实验协议（回测前就定好规则）**
开发数据用哪几年、验证数据哪几年、最终**盲测**数据哪几年；一次实验最多改几个变量；交易成本多少；什么算通过、什么算失败；什么时候必须停止优化。
> 很多人以为 AI 量化最重要的是"选哪个大模型"，其实真正决定结果可信度的**往往不是模型，而是实验协议**。

### 5 · 如何把模糊想法交给 AI：一张"研究假设卡"

以最常见的**动量现象**举例（原始观察：过去一段时间表现强的股票，未来可能继续较强）。

- ❌ 错法："帮我写一个高收益的动量策略。" → AI 会直接进入优化模式，不断组合参数（=过拟合起点）。
- ✅ 对法：先让 AI 生成一张**研究假设卡**：

| 项 | 内容（示例） |
|---|---|
| 1. 市场观察 | 过去 20 交易日、相对行业更强的股票，未来 5 交易日可能仍有收益延续 |
| 2. 可能机制 | 信息反应不足 / 机构持续建仓 / 注意力逐步扩散——**只是待验证解释，不是事实** |
| 3. 信号定义 | 在 DT 日收盘后计算：20 日相对动量 = 股票过去 20 日收益 − 所属行业过去 20 日收益 |
| 4. 数据时间 | 因用了 DT 收盘，信号只在 DT 收盘后完成；最早合理交易时间是 **DT+1 交易日**（不能一边用 DT 收盘、一边又假设能按 DT 收盘价成交） |
| 5. 预测目标 | 测 DT+1 日开盘 → DT+6 日开盘的收益（约 5 个交易日持有期） |
| 6. 基准 | 不能只跟 0 收益比；至少比：市场等权组合、普通 20 日绝对动量、行业中性后的随机组合、相同市值+相同流动性的股票组合 |
| 7. 混杂变量 | 动量收益可能其实来自小市值 / 某些行业 / 高 Beta / 高波动 / 流动性差 / 某段牛市——**必须做风险暴露分析** |
| 8. 失败标准 | 分组收益无单调性；样本外 Rank IC 接近 0；收益只集中在某一年；加入交易成本后收益消失；只有某个极端参数有效；去掉少数股票后收益大幅下降 |

> 假设卡的精髓：**它不是先证明策略一定有效，而是提前规定"什么证据出现后，我们应该承认它可能无效"。**

### 6 · 三组常见错误提示词与正确改法

| 错误提示词 | 为什么错 | 正确改法 |
|---|---|---|
| "帮我写一个年化收益 100% 的策略" | 引导 AI 不断迎合历史数据 | "请把这个市场观察转化为一个**可证伪的研究假设**。不要优化收益，也不要写代码。" |
| "这个策略回撤太高，帮我多加几个过滤条件" | 让 AI 不断切割历史样本，极易过拟合 | "请先判断回撤来自**市场 Beta / 行业暴露 / 流动性 / 信号失效 / 执行成本**中的哪个。每次实验只改一个变量。" |
| "帮我证明这个策略为什么有效" | 问题本身已带方向性偏见 | "请**同时列出支持与否定**这个策略的证据，并设计能够**证伪**它的实验。" |

## 贯穿主线：AI 的快，是优势也是风险

过去一个人一个月只能测十几个想法，现在 AI 一天能生成几十个策略。**你测得越多，偶然撞到一条漂亮曲线的概率就越高**——所以你得到的未必是 Alpha，也可能只是 AI 高速制造出来的过拟合。

> 记住这句话：**AI 不会直接把 Alpha 送给你，它只会让你更快地验证 Alpha。**

## 术语速查

| 术语 | 含义 |
|---|---|
| 量化信号 | 满足定义明确/时间明确/可计算/可回测四条件的交易依据；否则只是"观点" |
| 传统 ML 模型 | XGBoost / LightGBM / 随机森林 / 神经网络等，本身即预测模型 |
| LLM / AI Agent | 大语言模型，擅长阅读、提取、结构化、写代码、跑回测，是"研究助理" |
| 未来函数 | 用到了当下还拿不到的未来信息（如用当天收盘却假设按当天收盘成交） |
| 数据泄露 | 训练/回测中混入了本不该被看到的信息 |
| 幸存者偏差 | 只用今天still存在的股票池回测历史，忽略了已退市/消失的样本 |
| 复权 | 对除权除息做价格调整，未正确处理会污染收益计算 |
| Rank IC | 因子排序与未来收益排序的相关性；接近 0 视为信号无效 |
| 研究假设卡 | 把模糊想法结构化成可证伪假设并预设失败标准的模板 |
| 实验协议 | 回测前锁死的数据划分、变量数、成本、通过/失败/停止标准 |
| Purge / Embargo | 滚动训练里用于隔离训练与测试、防数据泄露的机制（下篇详解） |
