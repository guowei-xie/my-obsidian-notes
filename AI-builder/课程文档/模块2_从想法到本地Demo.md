# 模块 2 · 从想法到本地 Demo

> 时长:60 min | 形式:动手工作坊 | 受众:PM/管理层/BI分析师

## 一、本节目标

本节是上午的动手环节。结束时,**每个人都要在自己电脑上跑出一个能用的 Demo**——一个读取 CSV、画出图表的 BI 小看板。

具体目标:
1. 学会用 AI 工具「描述需求 → 拿到代码 → 本地跑起来」的完整闭环。
2. 体会「会一点 Python」的价值:能看懂 AI 写的代码、能改一两个地方让它更合心意。
3. 拿到一个属于自己的本地 Demo,作为下午「上线」环节的素材。

> 一句话:今天不要求你会写代码,只要求你**会让 AI 写、会看、会跑**。

## 二、课前准备(环境清单)

请在上课前完成,讲师会预留 10 分钟兜底排查:

| 项目 | 说明 | 检查方法 |
|---|---|---|
| Python | 3.9 及以上 | 终端运行 `python --version` |

## 三、讲师讲稿(引导部分)

**⏱ 0:05–0:08 演示成品**

## 四、动手步骤

### 步骤 1:把需求说给 AI 听(⏱ 8 min)

**做什么**:用一句话把你要的看板描述清楚。

**怎么向 AI 提需求**(可直接复制):
> 我会一点 Python,但不是工程师。请用 Streamlit 帮我写一个本地能运行的 BI 小看板,要求:读取同目录下的 `sales.csv`(列:日期 date、地区 region、销售额 amount);页面顶部有一个地区下拉筛选;下方按日期画销售额折线图,并显示总销售额。请给出完整代码,并告诉我怎么运行。

**预期结果**:AI 返回一段完整的 `.py` 代码 + 运行命令。

### 步骤 2:把代码放进文件(⏱ 5 min)

**做什么**:新建文件 `app.py`,把 AI 给的代码粘进去保存。下面是一份**最小可运行示例**,可作对照:

```python
import streamlit as st
import pandas as pd

st.title("销售小看板")

# 读取同目录下的 CSV
df = pd.read_csv("sales.csv")

# 顶部:地区下拉筛选
region = st.selectbox("选择地区", df["region"].unique())
filtered = df[df["region"] == region]

# 指标:总销售额
st.metric("总销售额", f"{filtered['amount'].sum():,.0f}")

# 折线图:按日期看销售额
chart_data = filtered.groupby("date")["amount"].sum()
st.line_chart(chart_data)
```

**预期结果**:文件保存好,和 `sales.csv` 放在同一个文件夹。

### 步骤 3:没有数据?让 AI 造一份(⏱ 5 min)

**怎么向 AI 提需求**:
> 帮我写一段 Python,用 pandas 生成一份示例 `sales.csv`,包含 date、region、amount 三列,3 个地区、最近 30 天的数据,数值随机但合理。

**预期结果**:运行后得到一个 `sales.csv`,步骤 2 的代码就有数据可读了。

### 步骤 4:本地跑起来(⏱ 5 min)

**做什么**:在文件所在文件夹打开终端,运行:

```bash
streamlit run app.py
```

**预期结果**:浏览器自动打开 `http://localhost:8501`,看到你的看板。

### 步骤 5:微调,体会「会 Python」的爽点(⏱ 7 min)

**做什么**:挑一个小改动,自己改或让 AI 改。

**示例提示词**:
> 把折线图换成柱状图;再加一个多选框,可以同时比较多个地区。

**预期结果**:改一行、存盘,页面自动刷新(Streamlit 会提示 Rerun)。你会发现:看懂 AI 的代码 → 提一句话 → 立刻见效,这就是今天的核心体验。

## 五、常见问题与排错

| 现象 | 原因 | 解决 |
|---|---|---|
| `command not found: streamlit` | 没装或没装进当前环境 | 重新 `pip install streamlit`,或用 `python -m streamlit run app.py` |
| `FileNotFoundError: sales.csv` | CSV 和 `app.py` 不在同一文件夹 | 把两个文件放一起,或在代码里写完整路径 |
| `KeyError: 'region'` | CSV 列名和代码不一致 | 把代码里的列名改成你 CSV 的真实列名 |
| 页面打开是空白/报红 | 代码里有报错 | 把红色报错整段贴给 AI:「这是报错,怎么修?」 |
| 浏览器没自动打开 | 环境限制 | 手动访问终端里显示的 `http://localhost:8501` |
| 中文图表乱码 | 字体问题 | 本节用 `st.line_chart` 一般正常;若用 matplotlib 需另配中文字体 |
