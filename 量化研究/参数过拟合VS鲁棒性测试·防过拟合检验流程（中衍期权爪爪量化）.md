## 一句话是什么

**策略验证的核心不是做出一条漂亮的回测曲线，而是证明策略不靠运气、不靠"参数碰瓷"。** 绝大多数失效策略并非"行情变了"，而是从一开始就是参数过拟合的伪策略。防过拟合的黄金体系 = **参数扫描（看地形）+ 蒙特卡洛/置换检验（看统计显著性）**。

## 为什么值得学（可迁移价值）

这是一份可直接抄作业的**过拟合体检清单**。它把抽象的"别过拟合"落成了可操作动作（扫哪些参数、画什么图、跑什么检验）和可判定的数字阈值（P<0.05、Z>2、看盈利区间连不连续）。凡是"调参 → 挑最优 → 上线"的工作（策略回测、超参搜索、模型选择、AB 实验挑指标）都能套用同一套"是真信号还是噪声"的检验逻辑。

## 参数过拟合的本质

- **是什么**：你反复调参找到的"最优组合"，很大概率只是**拟合了历史行情里的随机噪声**，不是稳定市场规律。
- **典型特征**：参数**稍微改动一点点，收益就直接崩塌**。
- **两个放大器**：
  1. **多重测试效应**——测试的参数组合越多，凭空跑出一条漂亮回测的概率就越高。
  2. **信噪比极低**——价格里绝大部分波动都是噪声，模型天然容易"记住假象"。

## 甄别真假第一步：参数扫描（看地形，不是找最优）

> **核心目标：扫描不是为了找最优参数，而是观测整个参数空间的"地形"。**

| 维度 | 做法 |
|---|---|
| 一维扫描 | 观察**单一参数**的敏感度 |
| 二维扫描 | 网格搜索 + 绘制**热力图**，看清参数间的交互关系 |
| 高维参数 | **不要**暴力网格，改用**随机采样** |

判据：
- ✅ **大片连续的盈利区间** → 鲁棒（稳健）。
- ❌ **孤零零的单一收益尖峰** → 基本可判定为过拟合。

## 第二步：叠加蒙特卡洛 / 置换检验（看统计显著性）

光做参数扫描远远不够，必须叠加蒙特卡洛类检验，判断收益究竟是**真实信号**还是**随机巧合**。

**看懂两个指标（同时满足才算统计显著）：**

| 指标 | 阈值 | 含义 |
|---|---|---|
| P 值 | **< 0.05** | 收益由随机产生的概率足够低 |
| Z 分数 | **> 2** | 收益相对随机分布偏离足够远 |

**进阶三种变体：**
- 信号时间随机化
- 收益自助重采样（Bootstrap）
- **最强：参数空间蒙特卡洛**——随机抽取多组参数批量检验，**避免只拿最优参数自欺欺人**。

## 完整标准流程（七步）

1. 参数空间定义
2. 一维、二维扫描
3. 蒙特卡洛 / 置换检验
4. 参数空间蒙特卡洛
5. 前向滚动验证（Walk-Forward）
6. 综合打分评估

> ⚠️ **高频错误**：写滚动验证时**混淆"扩展窗口"与"独立分块"**，错误划分训练/测试集，**间接引入未来函数** → 所有回测结果全部失效。

## 四条实操红线

| # | 红线 | 说明 |
|---|---|---|
| 1 | 不要只针对最优参数跑蒙特卡洛 | 只测最优参数 = 自欺欺人，要测整个参数空间 |
| 2 | 区分"低效"与"鲁棒" | 全体参数收益都趋近于 0 **不叫**稳健，那是策略无效 |
| 3 | 收益阈值只是行业经验参考 | 趋势策略 / 高频 / 低频标准不能一概而论 |
| 4 | 回测代码必须显性标注交易假设 | 明确区分**纯多头**与**多空双向**的收益率计算逻辑 |

## 贯穿主线

> **量化没有捷径。** 漂亮的回测随处可见——只有能通过整套鲁棒性检验、经得起样本外考验的策略，才具备实盘价值。

## 术语速查

| 术语 | 含义 |
|---|---|
| 参数过拟合 | 最优参数只拟合了历史噪声，非稳定规律；参数一动收益就崩 |
| 多重测试效应 | 测的参数组合越多，凭空撞出漂亮回测的概率越高 |
| 参数扫描 | 遍历参数看整体"地形"，判断盈利区间是连续还是孤立尖峰 |
| 热力图 | 二维网格搜索的可视化，看参数交互 |
| 蒙特卡洛检验 | 用随机模拟构造对照分布，判断收益是否显著 |
| 置换检验 | 打乱信号/收益重跑，检验收益是真信号还是巧合 |
| P 值 | 收益由随机产生的概率；<0.05 才有显著性 |
| Z 分数 | 偏离随机分布的标准差倍数；>2 才有显著性 |
| 参数空间蒙特卡洛 | 随机抽多组参数批量检验，避免只看最优参数 |
| 前向滚动验证 | Walk-Forward，按时间滚动划分训练/测试，模拟样本外 |
| 扩展窗口 vs 独立分块 | 两种滚动划分方式，混用易错误引入未来函数 |
